# neuromorphic_controller

### What is this? 

This is a work-in-progress neuromorphic controller for a physical rover, built to help me understand brain-inspired computing from the ground up. 

### Who am I?

I'm a Junior CS student at Florida Atlantic University. My true passion is neuromorphic computing, so I decided to log my journey self-teaching it to myself here, using the rover as a pedagogical vehicle. 

### Where its headed

The roadmap is roughly: 

neuron → synapse → STDP → dopamine → population coding → simulated environment → physical rover 

### Where are you getting your learning material from? 

I'm using Claude to structure my curriculum. I find that Claude has a great pedagogical approach, respecting my need to break up material into individual "chapters" for which he generates study guides and exams that I actually sit down to take. These study guides and exams will be posted in this repository alongside the code.
